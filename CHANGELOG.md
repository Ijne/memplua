# Changelog

## 0.2.0-alpha.2 — 2026-09-19

- Renamed the product and production entry point to memplua.
- Added the compact Windows installer with verified model downloads.
- Added the native desktop widget, RU/EN settings, review workflow, and knowledge graph window.
- Reworked extraction around durable analysis batches and atomic conspect review.
- Added canonical Term/Thought storage and a manifest-owned Obsidian projection.
- Improved Obsidian notes with readable filenames, richer content, and compact thought nodes.
- Removed language-rejection retries; extraction now asks the model to translate output to the selected language.

This is an alpha release. Existing canonical data is preserved, but installer,
long-running native audio, and recovery behavior still require broader testing.
