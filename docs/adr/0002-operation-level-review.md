# ADR 0002: обязательный review каждой операции

- Статус: принято
- Дата: 2026-09-10

## Контекст

Ответ локальной LLM является недоверенным предложением. Автоматическое слияние могло незаметно повредить пользовательскую базу знаний, а review целого документа не позволял принять только корректные части.

## Решение

Reconciler читает snapshot и создаёт `ChangeSet`, не изменяя graph. Каждая `ChangeOperation` имеет собственное решение `approve`, `edit` или `reject`. Только транзакция `DecideAndApply` меняет canonical graph и записывает revision с provenance до operation, conspect и chunks.

LLM может предложить только `create`, `update` или `noop`. Удаление canonical-объекта не является LLM-операцией и в будущем будет отдельной явной пользовательской командой. Неизвестная taxonomy создаётся отдельной pending-операцией; зависимый объект нельзя применить, пока taxonomy не одобрена или не удалена из пользовательской редакции.

## Последствия

Один change set может быть частично применён. Ошибка exporter-а не откатывает graph. UI обязан показывать операции отдельно и отправлять полное отредактированное значение для `edit`.
