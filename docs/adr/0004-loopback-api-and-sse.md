# ADR 0004: loopback REST API и SSE

- Статус: принято
- Дата: 2026-09-10

## Контекст

Desktop UI должен разрабатываться отдельно от Go runtime, принимать команды и восстанавливать состояние после перезапуска. WebSocket не нужен для однонаправленных уведомлений, а открытый сетевой интерфейс увеличивает риск утечки локальных транскриптов.

## Решение

Версионированный `/api/v1` слушает только loopback и требует локальный bearer token для всех путей кроме `/healthz`. CORS либо выключен, либо разрешает ровно один настроенный origin. Команды источников, review, graph queries, jobs, settings и export используют REST. Типизированные `AppEvent` сначала сохраняются в SQLite, затем передаются через SSE. `Last-Event-ID` воспроизводит пропущенную историю.

OpenAPI-файл `api/openapi.yaml` является контрактом между runtime и будущим UI.

## Последствия

UI может перезапускаться независимо и не теряет уведомления. Token остаётся локальным секретом. Изменения несовместимого контракта требуют новой версии API.
